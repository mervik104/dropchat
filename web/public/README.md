# DropChat icon placeholders

Swap the SVG files in this folder to change the installed/PWA artwork:

- `favicon.svg` — browser tab.
- `icon-192.svg` — PWA / Android home screen.
- `icon-512.svg` — PWA / store / splash.
- `maskable-512.svg` — Android adaptive icon (keep the safe margin).
- `manifest.webmanifest` — update colors and icon paths here if filenames change.

The in-app logo lives in `src/ui/Logo.tsx` and is the only logo component used by the UI.
